# 亲和力与结构引导

新的组合接收已有证据绑定的结构 RewardProgram，以及显式 DesignIntent。它保留 StatePacket、诊断与知识库来源，指定一个主要 affinity head，允许分子改变化学图。当前 FLOWR 适配器保持有效原子槽位数不变。

## 奖励与消融

对当前采样时刻的活预测 a，使用 `U = 2 tanh((a - a_control(t)) / 2)`。对照来自同一个完整运行检查点的无引导轨迹，只在已覆盖时段内插值。1 个 pK 单位是实验归一化尺度，不代表预测误差；四个 head 分别报告。

保留结构的消融仅在原奖励上增加 `w_A U`。放开保持约束的消融移除固定初始图排序、持续贴近初始坐标的代价和相对初始坐标的全局位移限制，使用 `w_A U - balance(geometry, clash) - pocket`。balance 延续 log-mean-exp 聚合，tau=0.1、rho=0.05。pocket 为各原子到最近蛋白原子距离超出 4.5 Å 部分的平方均值，以 1 Å 归一化。新增引导提案若存在原子距所有口袋原子均超过 8 Å，则拒绝。该近似约束只检查口袋占据，不代表有利结合接触。

局部消融保留原有诊断区域的几何损失。全分子消融覆盖当前图上所有可支持的重原子键与键角，改用 `sqrt(1 + mean(relu(abs(z)-1)^2)) - 1 + 0.1 mean(z^2)`。z 为相对当前图 MMFF 参照的偏差，以键长参照的 10% 或 30° 角度归一化。均值降低项数的影响，小的平滑项让容许区间内仍有几何改善梯度。这个消融同时改变范围与聚合，不能独立归因于其中一个因素。

离散图改变后重绑几何参照。缺失必需参照时拒绝评价。扭转、平面性以及 MMFF 弛豫代理仍属于独立验证，未声称已纳入可微奖励。

## 执行约定

affinity 活张量和结构输出取自同一次模型前向。总奖励经模型对当前潜变量坐标求导，按适配器的正向 flow 时间约定注入。候选比较使用相同下一时刻、自条件缓存和目标定义。化学有效性、严重碰撞及口袋约束检查的是新增引导；原生采样仍可能产生无效输出，终态需要独立筛选。

每原子的单步与累计路径预算限制新增控制量，不等于原生动力学与引导共同造成的总位移。扩大预算单独作为实验。输出分子不做后处理最小化，应变评价的最小化只操作副本。

## 离散分支

可选策略在声明的时段内，对低置信度类别分布使用 `q(c) ∝ p(c)^(1/T)`。只作用于目标 batch 项和最大类别概率低于阈值的槽位，保留键矩阵对称性与对角线。相应自条件字段同步使用修改后的预测，再由原生积分器采样下一状态，不直接覆盖当前原子标签。

每个分支恢复同一完整检查点与随机数状态。温度改变提案分布，既不是换随机种子，也不是校准概率或离散变量梯度。坐标提案接受分数来自实际转移状态的重新前向，不能沿用改标签前的旧 affinity。各完整后缀独立评价；这是小规模固定候选搜索，没有实现束重采样或论文中的重要性采样算法。

## 复现

使用原 FLOWR 环境和 MolSteer 安装，无需新增依赖。运行 `scripts/validate_affinity_generation.py`，以 `--base-config` 指定已验证的 t=0.50 配置，以 `--output` 指定新目录，再运行 `scripts/evaluate_exact_continuations.py --root <output>`。程序记录路径、奖励、预算、分支和来源哈希。通用 Executor 也支持 affinity RewardProgram 与 `control_trajectory` JSON 路径。

本实验只检验一个起始分子/检查点。所有终态及四头、有效性、碰撞、几何和同图弛豫代理均应展示，不能只保留表现最好的分支。优化目标 head 上升不构成真实结合亲和力提升的独立证据。
