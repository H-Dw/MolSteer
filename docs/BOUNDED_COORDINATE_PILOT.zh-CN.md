# 条件坐标试验配置

`thinker.execution_scope` 默认为 `complete_goal_set`。生物专家判定必要、但执行通道尚不支持的目标仍阻止执行。

显式设置为 `bounded_coordinate_pilot` 时，可对已验证的坐标目标做局部机制试验。完整生物计划与数学设计保留在 RewardSpec 中，`partial_execution` 记录未解决的必要目标，并将 `complete_goal_set_resolved` 标为 false。此配置不声明完整分子质量修复，也不把元素身份等目标改名为已完成或监测项。

必要保留约束必须全部可执行；不能跳过优化目标依赖的保留条件。表达式、证据绑定、数值与实时梯度检查，以及设计声明的图变化适用性策略仍执行。原子槽位的后续类别变化不是坐标目标已解决的证据，最终结构与质量应另行评估。

本配置用于明确缩小试验范围，不影响目标选择与知识检索，也不在 Skills 中写入分子、时刻、参考距离或奖励函数。
