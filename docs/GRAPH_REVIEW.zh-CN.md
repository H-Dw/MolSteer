# 连续坐标奖励、化学角色与图变化复核

2026-09-30。本文说明本轮代码修改与适用范围。

## 坐标优化为何仍可能依赖离散化学信息

常规 run_suffix 对当前坐标 X_t 求导，通过模型预测端点 X_hat_1 计算奖励，再把有界位移加入坐标。它没有对原子、电荷或键类别执行直接梯度更新；这些类别仍由原生积分器采样，坐标扰动也可能间接改变下一次类别预测。

必须区分函数的数值定义与化学适用性。纯粹的距离 d(i,j) 和角度 theta(i,j,k) 在换图后仍可计算；如果目的始终是让两个空间槽位接近，通常不需要换函数。但若目标是“将某根化学键拉到合理键长”，参照长度、容差以及这两个槽位是否仍然成键都依赖当前图。

| 奖励类型 | 离散信息改变的影响 |
| --- | --- |
| 固定空间锚点、纯坐标位移预算 | 公式通常不依赖元素、电荷和键；仍需确认原槽位是否继续承担相同任务 |
| 键长/键角区间残差 | 函数形状可继续使用，目标键/角、参考值与尺度可能需要更新 |
| 半径定义的排斥/碰撞 | 元素变化会改变半径；换键还会改变需要排除的成键或 1–3 原子对 |
| MMFF 应变 | 原子类型、形式电荷、隐式氢和键阶影响力场参数与同图弛豫参照，必须使用当前图 |
| 特定官能团、供受体或带电中心目标 | 槽位仍在，化学角色可能已变；需重新诊断适用性 |
| 实时模型亲和力 head | 当前前向计算反映当前状态；不能复用更改类别之前的旧 head 作为新图评分 |

可把图条件奖励写成 R(X;G)。在当前图 G_t 固定的分支内计算偏导 dR/dX，不意味着 G_t 在后续时间必须等于 G_0。若程序实际使用 R(X;G_0)，换图后数值函数仍可能可微，但它未必还测量原本想修复的化学问题。

creativity 的几何参照已经按当前图查询；selection、AgentMixedReward 和一般 expert 表达式中的固定常量不会自动获得新的化学意义。本轮为这些 Agent 路径增加了复核入口，并为 expert 的 MMFF 评价传入当前图。

## “初始图偏好”的精确定义

`MolecularReward.__init__` 将初始预测的 atomics、charges、bonds 概率保存为 p0。`graph_cost` 对证据选择的局部原子槽位、其形式电荷以及区域内部原子对计算：

```text
C_G(G) = mean_k log((max_c p0[k,c] + epsilon) /
                   (p0[k,current_category_k(G)] + epsilon))
R = -L_geometry_clash_pocket_movement - lambda_graph * C_G
```

例如初始某槽位 P(C)=0.8、P(N)=0.1，后续选择 N 时，这一项的未平均代价约为 log(8)=2.079。实际程序会对所有被纳入的原子、电荷和区域内原子对取平均，再乘 lambda_graph。它是冻结边缘分数构造的正则项，不是完整分子图的联合概率。

类别由 argmax 决定，p0 已 detach。因此在同一离散分支内 C_G 对坐标的导数为零，但两个候选的类别不同时，它会改变奖励分数和接受结果。它不是全局锁图；区域外未参与计算的类别变化也不会被该项直接惩罚。

| 取消该偏好（lambda_graph=0）的收益 | 代价与需要验证的问题 |
| --- | --- |
| 不再把 t=0.50 的不确定预测当作长期类别参照 | 减少了一项保守正则，受未校准奖励驱动的候选可能更偏离模型支持 |
| 允许后续证据支持的元素、电荷、键阶与连接关系不因早期低概率而单独受罚 | 类别抖动、稀有化学状态或奖励投机可能增加，需用真实续推判断 |
| 接受决策更贴近当前任务奖励与当前化学可行性 | 对新图的参数覆盖、角色重绑定与独立终态评价提出更高要求 |

移除该项不会自动启用离散梯度优化，也不会自动提高分子质量。原生生成模型仍提供类别分布；候选有效性与严重碰撞检查也仍存在。若需要正则化，应另行比较相对同一步原生分布的干预信任域，不能不经实验就当作更优方案。

本轮只分析该偏好的取舍，保留既有默认 lambda_graph=0.1 和历史配置。affinity_structure 的 retain_initial=False 等已有路径仍使用 lambda_graph=0。

## 已实施的变化

### ExpertReward

- 删除 `check_graph` 以及 prediction、state 视图上的全图签名相等要求。固定坐标表达式不会仅因元素、电荷或键类别改变而抛出“graph changed”。
- 保留坐标槽位数量与映射、程序来源、有限值、控制方向、预算和候选化学可行性检查。
- live MMFF 使用当前 prediction/state 的类别解码分子。MMFFStrain 仍为每张图建立自己的参照缓存；不能把初始图的力场类型直接用于新图。新图的化学准备充分性仍需 Reader/Thinker 复核，参数可算不代表物理适用性已经验证。
- 评价结果区分“坐标表达式已求值”与“化学适用性已审核”。

### Agent 工作流

适配器每段返回新的 enriched StatePacket 时，MolMonitor 独立比较 state/prediction 的元素、形式电荷与键关系。仅坐标、时间或类别置信度变化不触发这条通路；非有限数值仍优先走已有停止路径。

```text
新图事件
  -> MolReader 读取新 StatePacket，重新生成诊断
  -> MolThinker 比较旧奖励和新图的适用性
  -> 保留合理函数形状，按证据调整参照、作用槽位或函数
  -> MolExecutor 重新验证，再由适配器执行
```

不重新按元素排序张量，也不把新元素移入其他槽位。Reader 保留原始槽位 ID，更新其化学上下文；Thinker/Executor 根据新角色重新选择奖励支持与可编辑槽位。宿主显式声明的 `host_editable_atom_ids` 始终是上界。

终态已经生成时，新的图变化只触发最终重新读取，不再启动无剩余采样步骤的奖励执行。普通段内复核仍受 Agent 的 max_replans/max_segments 限制。

### FLOWR 实时入口

标准和 monitored 坐标执行器新增可选 GraphReviewSession，支持 `agent_expert` 与 `agent_mixed`。开启方式是在执行配置中加入：

```json
{
  "graph_review": {
    "agent_config": "/absolute/path/to/agents.json",
    "max_reviews": 4
  }
}
```

现有 Agent 续推入口也支持 `--graph-review-agent-config` 与 `--max-graph-reviews`。Agent 配置决定使用真实 API 还是显式 offline 算法；默认不隐式发起新的付费模型调用。

执行步骤：

1. 在引导前探测当前图，不消耗原生随机数或改动自条件缓存。
2. 图变化时保存当前阶段与运行检查点，由 MolReader 从真实文件重建 StatePacket。
3. 验证导出的预测图与触发事件的实时预测一致；将旧奖励和变化详情交给配置的 Agent。
4. 只有奖励程序通过验证、编译和实时有限差分预检，才安装新版本，并记录程序沿革与新可编辑槽位。
5. 恢复原生采样状态、自条件、RNG，保留累计位移预算和原坐标信任域，继续同一条轨迹。

图变化不会回滚原生采样。复核失败、设计延期或复核预算耗尽时，暂停额外引导，继续原生采样；不会悄悄采用一个备用奖励。已观察且未再变化的图不会每步重复调用 Agent；新的类别变化可在剩余预算内再次触发复核。

原生更新后的新图在下一步引导前复核。一个坐标候选若改变下一次预测图，不会仅凭“改图”被拒绝；若被接受，则记录下一步复核标记。候选仍受当前绑定下的数学评分和独立可行性约束，这一即时跨图评分是暂定比较，不能当作新化学解释已获验证。

AL、outcome_aware 等已有专用控制器的目标和参照契约不同，本轮不让普通 Agent 编译器静默替换它们；对这些控制器开启该选项会明确报错。未开启 graph_review 时，全图门禁仍已删除，但固定化学参照不会因此自动完成语义重绑定。

新奖励保存为声明式 `RewardProgram.json` 并在现有执行器中运行，不让模型生成任意 Python 代码。检查点保存已验证程序、有效槽位、复核状态和剩余预算，runner 续跑会恢复该程序。

## 验证范围

新增测试覆盖：元素、电荷、连接关系、键阶独立变化；坐标变化不触发化学复核；同图事件去重与续跑；Reader → Thinker → Executor 路由；MMFF 使用当前图；真实 Reader、显式离线 Thinker、编译与实时梯度预检；复核失败后完整原生后缀的状态、类别、自条件与 RNG 保持一致。

同时修复有限差分预检将“解析导数和数值导数都为零”误判为失败的问题。该修复仍要求正负扰动处于同一离散图，并未把图边界上的有限差分当作平滑导数。

测试使用本地 CPU、合成分子和测试适配器。没有在本轮调用付费 Agent API 或执行真实 FLOWR GPU 续推；实际终态质量、额外调用成本与复核频率仍需配对实验测量。
