# MolThinker：以生成中间态为起点的前向决策与函数构造方案

2026-10-01。本文保留视角纠正和修改规划时的核查记录。后续已按本方案修改实际双专家代码，详见[实施说明](MOLTHINKER_FORWARD_IMPLEMENTATION.zh-CN.md)；软件回归、真实 API 和续采样的验证边界分别记录。第 2、9 节描述规划时的历史状态，不代表修改后的运行状态。原核查只使用本地代码、知识库和已复制的公开实验产物，没有读取模型私有推理。

## 1. 纠正决策前提

决策起点是某个生成时刻的状态及其 MolReader 诊断，不是已经知道结果的两组干预实验。当前状态 `X_t`、当步预测 `prediction`、实际生成终态是不同对象。当步预测可提供当前化学假设下的结构信息，不能当作已观察到的未来终态。时间、噪声语义、表示映射及可控通道由实际生成器提供。

在没有干预与不干预结果先验时，不要求生物专家提供终态收益差、异常持续概率、修复成功率或修复保持概率；把未知值换成主观区间也不能补上证据。上一轮的 `terminal_gain × persistence × control × retention − damage − cost` 不适合作为本任务的前向选择依据，应从有效提示词、工具上下文和排序工具中撤下。

这里的**潜在收益**是当前证据支持的修复理由：目标直接处理什么缺陷，覆盖多少独立机制，可能解除什么局部可行性障碍，当前控制能否作用于它，以及可能损害哪些结构条件。它是带有适用范围和不确定性的机制判断，不是已校准的终态期望收益。观测值、知识中的物理关系、当前状态的局部计算可以支持这种判断；没有测量的未来结果不参与数值排序。

```mermaid
flowchart LR
    A[当前状态与 MolReader 多因素诊断] --> B[整合机制、假设和耦合风险]
    B --> C[评估潜在修复收益，选择最小充分目标集]
    C --> D[检索 knowledge，判断保留、特化或重构]
    D --> E[确定数学目标集合与局部响应]
    E --> F[构造并比较候选，再编译执行]
```

## 3. 生物专家：先整合，再选择

### 3.1 建立当前问题图

从 MolReader 的事实出发，连接“观测 → 缺陷假设 → 化学区域/机制 → 候选目标”。结合键长、键角/扭转/立体化学、分子内稳定性、位阻、靶点接触、表面/埋藏、化学身份/基团和任务相关信息，但不要求每个因素都有一个奖励项。

同一告警组可能包含多个独立机制；多个告警也可能反映同一个机制。按原子支持、化学关系和物理作用整理，不能只按空间距离或告警编号合并。原子支持重叠不证明因果关系，某条键异常也不证明它解释了全分子应变。保留竞争解释，例如构象应变与化学身份不确定性同时影响参考值。

将信息分成当前事实、机制假设和缺失信息。正常接触或构型可以提供保留理由，但不能自动成为固定整个中间构象的要求。生成中的分类通道可能继续变化，保留条件应针对有依据的化学关系和任务，而不是永久冻结当前槽位标签。

### 3.2 比较潜在收益

对独立候选目标回答六个问题，给出证据和短理由，不强制数字化：

1. 它是否直接处理一个当前有依据的缺陷，还是只改善方便计算的代理？
2. 它覆盖哪些独立问题；其他目标是否重复覆盖同一机制？
3. 修复它是否有理由改善构象可行性、保留有效接触或解除其他目标的局部障碍？这只是机制推断还是已有当前计算支持？
4. 当前阶段、控制变量和自由度是否允许作用于它？不支持的基团/身份改变需要何种独立通道？
5. 调整可能损害哪些邻接几何、构型或受体关系；哪些需要保留，哪些只能后续测量？
6. 哪个缺失事实会改变目标选择或修复方式；是否能用当前状态上的一次测量解决？

允许定性优先关系、条件依赖和暂时无法排序。不要把严重程度、实现便利、告警数量或理论药效想象变成价值分。现有 `rank` 若为兼容仍需连续编号，应作为交接次序；实际优先关系及未决比较写入公开摘要，不自动转换成权重或阶段。

### 3.3 最小充分目标集

令 `G*` 表示生物选择的优化目标，`C` 表示必要保留条件，`Q` 表示影响选择的未决信息。它们不是一个共同加权列表。

“充分”相对于当前有证据的修复范围和明确的化学假设：每个必须处理的独立缺陷都有直接目标，主要耦合风险有处理方式。“最小”通过删除检验判断：移除某个目标后，是否仍覆盖全部必要机制；若仍覆盖，该目标可能冗余。代理替换检验还要问：代理改善而缺陷不变的情况是否仍可能成立。

这两项是当前机制与目标覆盖的逻辑检验，不是要求预知干预结果。它们不能保证找到全局最小集合，更不能保证最终生成成功。一个目标充分时不制造第二项；两个独立问题必须处理时也不为了简洁删成一个。资料不够时可形成带条件的暂定集合，同时记录未决问题，不能把未覆盖的重要缺陷改名为“监测”后宣称完整充分。

**科学必要性与执行状态分开。** 某目标需要尚未接入的能量、表面或分类控制时，保留它的科学理由，交给数学专家检索、判断可迁移部分和缺失实现。只有明确缩小任务范围时才称“局部试验目标集”；不能因为当前后端只有距离函数，就倒推只有距离值得优化。

交接以现有 `summary`、`mechanism`、`priority_reason`、`repair_predicate` 和不确定性字段为主；辅助工作区保存问题归并、候选目标、入选/未入选原因、删除检验、保留条件和需要补的当前事实。允许部分草稿和修订，不以缺少工作区条目阻断提交。

## 4. 数学专家：检索帮助推导，而非公式装饰

先接收 `G*` 及生物机制、保留条件和不确定性。生物目标描述“要修复什么”，数学目标集合描述“什么关系/区域算作修复”；二者要区分。例如生物可以选择修复某键型下不合理的局部几何，具体数值容差应由数学专家结合来源、测量和当前假设确定，不必先由生物填写一个拍定的区间。

### 4.1 检索与迁移判断

按机制、测量对象和作用角色检索 [knowledge 函数表](../knowledge/Molecular_Generation_Control_Functions_Representative_Table_2026-09-19.md)，而非先选 `relu(distance)` 再找引用。每个候选来源说明原始对象、变量、公式、响应机制、前置条件、可迁移部分和不适用部分。只检索会改变函数选择或补足独立机制的资料，不按固定数量凑函数基。

| 目标/机制 | 可借鉴的知识 | 保留、特化或重构时要处理的内容 |
| --- | --- | --- |
| 键几何与容差 | G01 区间/单侧势，P01 分子内能量 | 保留目标集合语义或真实键型能量；特化键图、类型和原子支持。全分子稳定性不能由一条距离替代 |
| 键角、扭转、手性与共面 | G05 及 P01 的相应物理分项 | 保留周期性、有符号几何或耦合能量。若从符号判定重构连续势，说明这是新构造，不将其冒称原报告函数 |
| 接触质量与局部排斥 | G02、G04、P02、P03 | 区分单侧排斥、方向性、类型相关吸引及电荷作用；特化相互作用伙伴。更多或更近的接触不是普遍目标 |
| 整体构象稳定性 | P01 完整 MMFF、P04 残余力 | 能量与驻点条件是不同问题。沿用所选物理机制与真实评价器，不能统统降成坐标窗口 |
| 表面/埋藏与基团环境 | P06 SASA、P07 ESP 等 | 需要基团、面积/场参照和真实评价路径；数个距离不能替代面积或场。缺失时保留设计需求，不编造面积目标 |
| 保留已成立的关系 | G03 及相关几何/物理机制 | 选择有依据的关系和允许自由度，不把所有当前原子位置固定成理想构象 |
| 分类、黑箱或种群策略 | S01–S07 | 保留其原本角色或解释新的作用方式。种群 softmax 不能直接作为单分子目标聚合，分类偏好不自动有坐标导数 |

这些是检索方向，不是预置最终奖励。现有 21 张来源卡及 AST 序列化工具可以继续使用；11 种 helper 形状只是编译便利入口，不应成为数学推理的边界。

### 4.2 数学目标集合 → 局部响应 → 候选

对每个保留目标绑定观测量 `z_k`、化学假设、表示、可编辑支持以及目标集合 `T_k` 或有依据的优化关系。参照与容差要区分：一个力场平衡值不自动给出 ±10% 的容差；当前观测也不能自动成为应保持的物理边界。资料不足时记录未定参数或明确的局部试验假设，而不是发明狭窄窗口。

然后先写局部响应意图：哪种偏离需要什么方向的作用，哪些区域应无作用，接近修复时作用如何变化，何时可能出现奇异/饱和/耦合冲突。对可微局部势，可用

\[
q_k(z)=\frac{\partial f_k}{\partial z},\qquad
\nabla_X f_k=J_{z_k}(X)^\top q_k(z_k)
\]

表达这种响应。多变量响应需能由声明的势产生；如果选择的是约束方向求解，就报告该方向问题，不硬造一个标量势。对真实物理能量保留其耦合导数；对区间目标推导边界外的单侧响应；对角度、匹配或表面目标保留相应几何和相互作用机制。

由此构造适合该问题的候选，再决定必要的区域内整合与跨目标关系。不能先指定“加和/最大值/lp”，再编写生物理由。检查的是响应行为：是否重复计入一个缺陷，是否允许必要目标被补偿，较小的未修复目标是否失去作用，保留条件是否会被有限步破坏。`derive_allocation_operator` 可保留为确定响应关系后的计算工具；它不决定目标重要性，也不替代函数推导。

来源中的完整公式可以保留，条件和支持可特化；新的残差、平滑、局部近似或组合必须有自己的推导。数学创新来自问题结构、物理响应与控制路径的适配，不来自复杂算子数量。需要新评价器的候选先作为设计保存，不能静默改成无关距离代理。

最后才交给现有编译与数值检查。坐标副本响应可为当前局部选择提供计算证据；生成器的实时拉回、掩码、注入与完整续采样应分别报告。副本下降不被解释成未来生成收益先验。

## 5. 以保存的 5i0b、t=0.50 状态说明决策差异

以下仅从第 16 轮已复制的 StatePacket 和公开测量摘要说明问题，不是新 Agent 决策，也不沿用其奖励区间为正确答案。

该步 `prediction` 中有 4–12 键长 1.694 Å、MMFF 参考 1.469 Å；全分子应变代理约 26.91 kcal/mol，其松弛位移并不只集中在该键。局部角/扭转筛查没有异常；已有几何赋值的手性、94 个受体接触、0 个受体碰撞及埋藏观测。原子 4 的元素分布不确定，当前碳假设会影响键参数。`state` 视图另有中间分类 token 与键图可用性问题，不能和 `prediction` 的力场测量拼成一个物理对象。

新的生物决策不能直接等同于“拉近 4、12”：

- 比较局部键几何与分布式应变是同一机制还是两个独立问题；当前缺少能量分解时，不声称一条键解释全部应变。可补当前状态的分项或局部响应测量，而非先索要原生/干预终态结果。
- 若证据支持一个局部机制足以覆盖本轮修复范围，可选择一个目标；若存在独立构象负担，则应保留第二个目标或明确未覆盖的设计需求。现有资料尚不足以给这两种选择盖章。
- 受体接触、立体关系和邻接几何参与耦合风险判断。不能因接触计数正常就断言结合最优，也不能任意把当步手性体积的整个数值固定为真实目标。
- 化学身份不确定性使参考值具有条件性。距离移动不能宣称诱导了新基团；需要分类分支时应保留该设计需求并说明现有控制的范围。

数学专家随后比较 G01 局部集合、P01 耦合能量及相关保留机制的适用性，推导目标集合和响应。此前约 1.32–1.61 Å 的范围来自约 ±10% 的未校准试验假设；它不能只因数值测试通过就成为数学上必然的容差。

## 6. 如何帮助 Agent 实际进行前向决策

不能读取或证明模型内部私有思维。可控制的是有效提示词、可用信息、工作记忆和工具反馈，并检查公开决策、推导及实际工具行为。

**按阶段提供问题上下文。** 生物阶段收到当前表示、诊断与机制整理入口，重点问“哪些问题独立、修复理由是什么、哪组目标足够”；数学阶段先收到 `G*` 和必要机制，再获得有针对性的来源资料。随后提供“可迁移部分是什么、目标集合如何确定、应该产生何种响应”的短指引。完整验收 schema 保留为编译时可查资料，不充当第一轮设计任务。

**保存可编辑的公开草稿。** 工作区保存证据归并、候选和选择理由，以及来源迁移、目标集合、响应与候选摘要。复用现有工具的返回与草稿暂存，或提供一个可增量更新的辅助入口。允许模型一次完成多个环节，不要求每个小步骤单独调用工具，不用“调用顺序错误”制造异常。宿主整理事实和格式；科学选择与推导仍由专家完成。

**减少重复劳动和提示词竞争。** 补齐实际需要的参考内容，按角色分配；无需每个模型都读整份两阶段材料。保持模型回答所依据的上下文与最终提示词版本可核查。AST、来源 locator、常量去重、导数计算继续由宿主辅助，避免模型把输出预算花在重复组装上。

**用机制示例指导迁移。** 准备少量按当前问题选取的示例：相关告警归并成一个目标；两个独立缺陷不能删成一个；接触优化需考虑类型/方向及邻接应变；来源完整能量与新局部代理需作不同迁移判断。示例给出决策和推导摘要，不提供要机械复制的目标数、最终聚合式、默认系数或私有思维文本。

**提供局部实验反馈，帮助修订。** 使用当前状态上的能量/几何/导数和候选副本响应，返回实际数值与作用范围；模型据此修改目标、形状或构造。这些反馈服务于选择，不附加“工作区是否完整”的 gate。现有最终表达式、有限性、绑定和执行约束检查继续用于真实可执行性；不再堆叠自然语言来源一致性 gate 来代替设计帮助。

## 8. 验证“用于 Agent”与“提高性能”是两个层次

代码层先验证实际系统消息、工具参数和返回值：移除不成立的概率/收益要求；按表示传入事实；未实现科学目标可以检索；必要参考确实被模型看见；缺少辅助记录不会制造新的执行报错。语法测试或脚本模型只能证明这些接线。

真实 GLM-5.3 层检查公开产物是否体现“诊断 → 机制整合 → 潜在收益理由 → 最小充分目标 → 来源迁移 → 目标集合 → 局部响应 → 候选”，而不是只核对工具名或 JSON 字段齐全。评审独立目标有无遗漏、冗余是否减少、是否给出无依据容差、是否把物理/面积/分类需求偷换成距离。此质量评审作为实验结果和改进反馈，不成为线上新增拒绝 gate。

在相同状态、初始信息和调用预算下与原流程比较。初始 Agent 输入不含原生/干预终态结果；未来测得的结果只在决策完成后用于评价。不要只以输入字符数、工具调用完成率或标量奖励下降衡量数学专家的性能。

随后才在 `test` 副本上执行 5i0b 单分子、t=0.50 的真实生成流程，保持 GLM-5.3、MolMonitor 关闭和图复核关闭。五档外部强度 1、10、100、300、500 使用同一份已确定的函数和初始状态，报告局部修复、独立结构质量、新问题、实际引导及数值行为；目标选择理由不能从事后结果回填。`data` 继续只读。此阶段尚未执行。
