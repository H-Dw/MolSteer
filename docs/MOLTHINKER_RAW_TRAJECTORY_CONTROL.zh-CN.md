# Raw 轨迹追溯、价值排序与当前化学状态下的奖励机制

2026-10-02。本轮修改实际 MolReader、MolThinker 双专家工具循环和 MolExecutor。没有修改 `skills/`，没有调用真实 API 或重新生成分子。

## 1. 读取哪些状态，如何追溯

`reader.raw_reference` 控制读取同一条 raw 轨迹的哪些已保存节点。`configs/agents.json` 的参考时刻模板为 `[0.6, 0.7, 0.8, 0.9, 1.0]`；这些数值只在配置中，运行时代码不依赖这组值。使用时设置 `enabled=true` 并提供仓库内的 `manifest_path`。起点来自当前 StatePacket，终点由 manifest 的 `role=final` 声明，支持递增或递减时间约定。没有保存的节点明确记为缺失，不重新推理、插值或伪造测量。

例如，将以下内容合入运行配置的 `reader.raw_reference`：

```json
{
  "enabled": true,
  "manifest_path": "test/raw_reference/manifest.json",
  "reference_times": [0.6, 0.7, 0.8, 0.9, 1.0],
  "include_final": true,
  "views": ["prediction", "state"],
  "factors": []
}
```

每个节点按配置的因素分别记录测量可用性与异常。因素包括键几何、角度/扭转/立体化学、分子内稳定性、位阻、靶点接触、表面埋藏、化学身份和任务指标。保存两种互不混淆的追溯结果：

- 原异常在原化学假设下是否可比较；保留旧的 `classification`。
- 后续分子在当时化学状态下是否仍异常；新增 `current_condition_trajectory`、当前参数、原子类型、首次无异常节点、复发和缺失记录。

重定型后，旧的碳键解释可以失效，而新分子的碘键诊断仍然可读。某条键消失单独记为 `relation_absent`；它既不是测量缺失，也不是原键成功修复。完整价态或类别置信度筛查没有局部异常时，可以报告该节点未标记异常。未覆盖的局部测量仍保持未知。

`inspect_raw_goal_trajectory` 按候选目标的原子、证据或因素读取所有配置节点。每个专家初始输入包含节点列表、各节点因素诊断概览和独立指标趋势，细节可分页读取。MolReader 的 host 诊断索引留在 checkpoint，不在数学输入中再次复制。raw 亲和力、SA、应变与局部区域的同步变化只支持关联假设，不能当作干预收益或局部因果贡献。

## 2. 生物专家排序如何影响数学控制

生物专家的 `rank` 从交接顺序改为干预价值优先级。提示词和公开工作区引导它依次整合机制、评估潜在收益、选择最小充分目标集，再说明排序。考虑：持续未解决的缺陷、原生修复时机、可控性、独立缺陷覆盖、化学依赖、与有益原生演化的冲突，以及证据不确定性。不存在已知的 guided 终态收益；系统不合成成功概率或固定价值打分公式。

`value_assessment` 与 `priority_reason` 记录公开依据和相邻优先级的理由。数学专家收到完整 `biology_plan` 一份，以及只含方向 ID 的 `goal_index`，不再重复接收完整 `goal_pools`。

多目标数学设计支持显式 `strategy.priority_weights`。若专家未给出系数，配置 `thinker.rank_decay` 提供透明的顺序偏好：按可执行优化目标的排序位置依次分配 `1, decay, decay², …`。这是控制偏好，不是收益估计；保留约束不混入收益排序。默认衰减可在配置中更改，专家也可根据归一化尺度和实际导数给出系数与理由。

- `weighted_sum`：组合加权后的无量纲局部代价。
- `maximum`、`lp_norm`：对加权后的缺陷进行聚合，保留不同的激活和响应特性。
- `common_descent`：先形成按优先级加权的偏好下降方向，再投影到所有当前活跃目标均不增大的方向集合。不能简单把梯度缩放后送入最小范数凸组合，否则可能反过来给予低权重目标更大的位移。

这些系数不保证较高 rank 的目标在所有坐标上都有更大位移，也不保证严格的词典序优先；梯度大小、耦合和可行方向仍然影响结果。构造预览报告各目标实际响应、冲突和保留项的变化，由数学专家据此调整。没有增加排序评分 gate。

## 3. 数学专家可以返回生物假设

`request_biology_revision` 接收受影响目标、机制冲突、证据、建议修改和已有公开数学推导摘要。下一轮生物专家收到原计划与修改请求，可修订化学假设、目标集合、保留条件与 rank，并记录接受、修改或拒绝建议的理由。

只有生物方向内容完全未改变的数学草稿才可带入下一轮。改变或删除的目标会撤下旧草稿；修改草稿或重新测试也会清除旧的提交缓存，避免用先前通过的设计代替新设计。最终仍执行现有数值与绑定验证；没有新增固定往返步骤或审核 gate。往返次数由已有 `max_discussions` 控制。

## 4. 从初始图绑定改为当前化学解释

删除了宿主审核中“引用化学参数就必须 `suspend_on_graph_change`”的要求，同时删除 ExpertReward 对整张初始图的一致性检查。旧字段可以解析，但不再使整个奖励停止。

新增可微观测量：

| 观测量 | 当前化学解释 | 梯度对象 |
|---|---|---|
| `bond_length_error` | 实测键长减去当前图 MMFF94s 类型对应的平衡键长 | 配置原子槽位坐标 |
| `bond_angle_error` | 实测键角减去当前图 MMFF94s 类型对应的平衡键角 | 三原子坐标 |
| `typed_steric_overlap` | 当前元素范德华半径之和乘显式 buffer，减去距离后取正部 | 配体与固定受体之间的坐标距离 |

`current_reference_quadratic` 构造选项可生成这些动态偏差的归一化二次势，不需要写入固定键型的目标键长。范德华半径加 buffer 是明确的排斥筛查模型，不能宣称等同于完整相互作用能；buffer 与尺度仍要说明来源或试验假设。

执行时使用当前预测图；若作用于 state 表示，则使用当前 state 的类别与坐标。某个机制不能得到参数时，记录该方向不可用，其余独立机制仍可求导；依赖缺失保留项的目标不被当作完整可执行目标。键消失的键项返回零贡献并明确记录 `relation_absent`，不能据此宣布修复成功。坐标槽位与表示对应关系仍必须有效。

新增 `constraint_mode=native_nonincrease`，用于允许“保留代价不高于同一步原生提议”的约束。它不要求原生代价先等于零。这里的 baseline 是**当前采样路径上、相同时刻、未施加本次额外位移的原生提议**；不是独立 raw 轨迹的历史终态，也不自动实现面积或方向性的接触模型。`absolute` 模式仍可表达有依据的绝对可行域。

旧奖励里已经写死的数值常量仍是数值常量。关闭初始图锁不会自动把旧的固定键长改造成动态参数；需要重新构造奖励。

## 5. 如何应用化学身份条件化的局部物理势思路

该思路已经写入实际数学专家输入的 `function_derivation.conditional_physics` 和系统指引：

1. 检查最小充分目标集是否仍成立；机制冲突时返回生物专家。
2. 按机制检索 knowledge 中实际来源，分清保留、特化与重新构造。
3. 对有依据的当前化学假设，确定局部几何、类型化排斥和必要接触保留的目标关系。
4. 说明参考能量、归一化、半径、容许损失的来源，推导局部导数、激活/停止区域及耦合效应。
5. 构造候选，按 rank 分配优化力度，比较实际坐标响应。

现有实现支持当前类型的键/角偏差、局部排斥，以及已有完整 MMFF strain 评价器。局部二次偏差不冒充完整 MMFF 力场能；局部扭转/面外能量分解、方向性接触面积、多套完整化学假设混合仍需要对应评价器和参数。专家应保留这些缺口，不能仅用两条距离宣称已实现整个物理势。

对于 flow matching，势作用于当步预测时仍沿实际计算图拉回：`grad_x J = (d X_pred / d x)^T grad_X J`。当前离散化学假设用于参数解释，本次坐标求导不穿过类别 argmax；下一次评估重新解释。这是分段的条件化坐标控制，不能宣称严格流形投影、类别可微或终态质量保证。原有位移预算、拉回与同阶段提议比较保留。

## 6. 数学输入压缩与验证

数学初始输入只保留一份生物目标和一份 raw 概览；恢复输入只自动携带最近失败摘要、候选评审与材料索引。完整候选保留一份可读入口，重复方向副本不再一起注入。历史生物计划、数值依据等独立恢复材料仍可通过 `recovery_support` 按需读取。

工具历史按完整调用/返回轮次压缩，避免拆断供应商协议；最近保留的原始 AI 消息保持其供应商签名。完整草稿与测试参数不反复重放，工作区仅携带当前草稿摘要、最新验证和公开观察 ID。历史公开结果可按 ID 和 JSON 路径读取。`history_max_chars` 限制保留的历史轮次体积，`history_recent_rounds` 限制数量；它们不限制固定初始输入与当前工作区的总字符数，也不是 API token 硬上限。

离线验证覆盖当前类型改变后的参考与梯度、rank 对实际方向的影响、共同下降冲突处理、同阶段保留、缺失参数的局部隔离、专家往返、草稿失效、请求去重以及动态 raw 时刻。完整回归通过 410 项；最后的 raw 关系判断修正通过 35 项复测，最后的上下文/专家交接修正通过 22 项复测。Windows 下使用 Python UTF-8 模式运行已有测试，避免旧测试按系统 GBK 解码 UTF-8 样例。

已有 5i0b 保存结果的只读追溯覆盖起点与五个后续节点，产生 96 个节点/表示/因素诊断面板和 171 条异常追踪。末节点按当时状态解释为 64 条未再标记异常、105 条原键关系已不存在、2 条仍有警报；追踪可能跨表示或重复覆盖同一区域，这些数目不是独立缺陷数，也不是本轮引导修复数。

旧实验恢复输入的自动注入段从 157,794 字符缩减到 1,349 字符（99.15%）；完整材料仍可按需读取。这不是总输入 token 或费用的节省比例。没有新 API、guided 推理或亲和力/生成质量实验。结果与范围见[验证记录](../validation/raw_trajectory_control_20261002.json)。
