# MolThinker：未来价值选择与知识驱动构造

2026-10-01 视角纠正：本文件保留上一轮实现及验证的历史说明。这里的反事实终态收益排序不适用于没有干预/不干预结果先验的当前任务，相关模块已撤下。新的[生成中间态前向决策方案](MOLTHINKER_INTERMEDIATE_STATE_PLAN.zh-CN.md)及其[实施说明](MOLTHINKER_FORWARD_IMPLEMENTATION.zh-CN.md)为后续依据；下面的历史测试不是新流程的验证。

本次修改回应两个缺口：八因素覆盖并不自动产生有效的干预优先级；来源/表达式一致性检查也不自动帮助模型构造函数。下面描述公开的决策流程与数学推导摘要，不读取或重建模型的私有思维链。

## 从因素列表到干预决策

原生物专家虽然输出 `rank` 和 `priority_reason`，却没有显式组织“相对于不干预，某项修复会改变什么终态结果”。排序容易退化成告警严重程度或当前实现方便程度。数学执行器也不会把 `rank` 自动解释成奖励权重或分阶段调度。

新的决策对象是**干预机会**，而不是每条告警。先将一个机制的键、角、应变代理等相关信息归并，再对候选干预说明：

- 不干预时的终态预测，异常是瞬态还是会持续；没有匹配续推时保留未知。
- 在剩余生成时间、可编辑自由度与位移预算内，修复成功的可能性。
- 修复是否会被原生采样撤销，或影响已有接触、立体构型与其他稳定条件。
- 成功且保持的修复能带来什么独立终态收益；代理值下降不直接成为收益证据。
- 失败尝试也可能产生的副作用、计算/干预成本，以及会改变当前选择的测量。

理论目标是有预算的反事实比较：

\[
V(a\mid s_t,B_t)=\mathbb E[U(s_1^a)-U(s_1^{native})\mid s_t,B_t]
-\mathbb E[D(a)]-C(a).
\]

这里的效用、损害与成本需要共同且有意义的单位，不能任意把 Å、kcal/mol、秒和亲和力分数相加。没有共同单位时，保留多维/定性比较。

`compare_intervention_opportunities` 支持一个可选的区间近似：

\[
V\approx\Delta U\;p_{persist}\;p_{repair\mid persist}\;p_{retain\mid repair,persist}
-\mathbb E[D]-C.
\]

概率是条件概率，不假设各因素独立。`terminal_gain` 是“相关缺陷修复成功且保持”条件下的增益幅度，不能再次包含相同的成功概率；副作用和成本涵盖失败尝试。所有区间由专家提供并说明依据，宿主不从告警等级生成概率。它们不是统计置信区间，也没有自动获得校准。

工具只输出偏序：一个候选收益下界高于另一个上界时，才标记稳健优先；区间重叠、效用不同或估计未知时不强行排序。同机制方案可以比较，但其收益不可累加。不可补偿的保持条件独立列出。排序后的选集还需检查依赖、重复机制、相互损害与预算，不能机械取前 k 项。缺少输入但可能有高未来价值的方向被保留为研究/设计机会，不记为零价值。

### 在 5i0b / t=0.5 上的公开决策示例

这是假设性决策演示，不是新 GLM 请求产生的判断：

| 信息 | 需要比较的未来价值 | 合理去向 |
|---|---|---|
| 局部键长异常 | 是否会持续到终态，局部修复是否改善独立几何，是否只是化学图假设变化 | 有条件的局部修复候选，附图适用性与反证 |
| 全局应变代理偏高 | 是否有完整力场/质子化依据，局部键与整体变形的因果关系 | 可能有高价值；不能因单距离可微就把它替换掉 |
| 已有候选受体接触 | 修复键长是否损失已有配对；距离候选不能证明氢键方向正确 | 有依据的接触保持项，额外相互作用含义单独评价 |
| 当前手性几何 | 哪些可动支持可能使其翻转，是否有目标立体构型参照 | 当前几何保持与目标 R/S 身份分开 |
| 面积/基团倾向 | 是否有指定目标、可微评价或离散操作路径，终态收益是否可测 | 高价值但缺输入时保留研究/设计机会，不伪装成坐标梯度 |

不能预先断言键长一定排名第一，也不能断言八项都应进入奖励。若原生续推会自行修复某个严重中间态，而另一项较小异常持续并导致终态失败，后者可以获得更高干预优先级。

## 从知识函数到新数学式

函数表应作为机制与算子的参考，而不是给最终公式附上引用的清单。新的前向过程是：

1. 从生物决策确定物理关系、控制角色和终态价值假设。
2. 检索真实函数并提取机制：测量变量、目标集合、局部形状、适用条件、梯度/搜索对象。
3. 指定变量和支持，决定保留、特化或替换哪一部分；完整 MMFF、单侧排斥、方向性作用和种群重采样不能互相混称。
4. 从目标集合与期望响应推导局部残差，再决定归一化和曲率；没有标定依据时只提出有界试验。
5. 合并一个机制内重复的关系，再分析独立目标之间是同时满足、允许补偿、需要保持还是冲突。
6. 在坐标副本上检查边际响应、掩码后的范数、方向关系及保持项的一阶影响，修改候选后再进行原有完整执行验证。

`prepare_function_synthesis` 返回真实原式及 21 类函数的迁移说明。例如：P01 的价值在于键/角/扭转/非键能的耦合，G04 的价值在于方向参照，G05 需要符号或周期几何，P06 需要真正的 SASA 路径。缺少评价器的函数保留其科学价值和扩展条件，不自动退化成距离窗口。种群函数的角色也保留，不能引用 S02 来证明分子内聚合器。

`construct_direction_potential` 根据专家选择的关系、来源、目标、尺度和算子生成草案。宿主承担 AST、来源原式复制、常数去重、条款对应和导数示例的机械工作；不推定新的生物目标或物理容差。当前构造支持区间、单侧、中心二次、周期、方向一致和带符号余量等局部形状，以及同机制的单项/最大值/非负残差和。自由表达式草案仍可使用，构造库不是唯一允许的公式集合。

新式可以来自不同的数学动作，而非多加一个坐标权重。例如：

\[
F_{torsion}=\tfrac12\left(\operatorname{wrap}(\phi-\phi^*)/s_\phi\right)^2,
\qquad
F_{chirality}=[m-\sigma v]_+/s_v.
\]

前者改变变量的拓扑处理，后者改变有符号几何的可接受集合。它们仍需要参照与尺度；体积 hinge 被明确标为对已报道符号机制的新代理，不冒充原报道角度能量。完整物理评价器可作为构件，超出当前表达式后端的评价器不会由工具虚构。

### 由期望边际响应反推组合参数

对于已决定采用范数的候选，`derive_allocation_operator` 支持反推参数，而不是默认使用 p=2。当前执行器的平滑均值范数为：

\[
A=(\operatorname{mean}(F_i^p)+\varepsilon)^{1/p}-\varepsilon^{1/p},
\quad
\frac{\partial A/\partial F_1}{\partial A/\partial F_2}
=\left(\frac{F_1}{F_2}\right)^{p-1}.
\]

在两个正残差的设计点，专家若选择期望敏感度比 q，则：

\[
p=1+\frac{\log q}{\log(F_1/F_2)}.
\]

纯数学示例：F1=0.6、F2=0.2、q=2 得到 p≈1.63093。测试通过实际执行器的自动微分核对比值为 2，而不是只检查字段。它是新组合的推导，不是知识表中报告的最终式；生物排名也不自动变成 q。尺度、投影后的梯度和其他状态下的响应仍须比较。相等残差不能识别 p；超出当前支持范围的解不被静默截断或换成固定模板。

`compare_constructed_architectures` 不选择默认架构。它可显示 maximum 对较小残差的零边际分配、相反梯度导致的共同下降驻点，以及归一化带来的范数差异。它只比较同一表示的坐标副本；混合 state/prediction 且没有实时映射时不声称获得了共同可行方向。保持项在零违反处的零梯度也不证明有限步保持。

## 本次改动和验证范围

没有给 BiologyPlan/MathematicalDesign 新增必填预测字段，也没有新增未来价值分数、函数迁移或候选比较的提交 gate。辅助工具输入未齐时返回 `needs_input` 和建议，不抛出执行异常或消耗 `run_tools` 修复预算。原有来源绑定、单位、数值与执行边界继续放在最终验证。

双专家指引已改成前向步骤；机会比较和数学构造记录保存在独立 `expert_workspace_history`，不改变旧 RewardSpec 的内容绑定。正常旧方案可以不调用这些工具。模型参数没有训练；这次改的是决策表示、指引、工具和上下文，而不是宣称大模型已获得了经过学习验证的物理能力。

| 模块 | 作用 |
|---|---|
| `agents/opportunity.py` | 条件反事实区间比较、未知项和不可补偿保持的分离 |
| `agents/reward_synthesis.py` | 真实函数迁移卡、局部表达式构造、响应参数反推、坐标副本候选比较 |
| `agents/experts.py` | 前向双专家指引、五个辅助工具、草案复用和机会记录传递 |

本次验证不新增 API 请求，也不运行实时生成器或五档 GPU 续推。历史 GLM 的 HTTP 402 和 GPU=0 记录不被改写为成功；本次没有新声称其资源已恢复。测试与回放结果位于 `outputs/constructive_thinker_20261001`。
