# 将无引导终态纳入 MolReader 与 MolThinker

本轮评估对象为 `5i0b_A__5vef_M77/ligand_002` 的 t=0.50–1.00 续推。中间态诊断仍绑定原 StatePacket；已完成的无引导终态与引导终态作为附加证据，不改写当时的观察。此处描述的奖励扩展尚未投入新一轮生成。

## 已实现的信息获取

| 收集器 | 新增证据 | 解释边界 |
|---|---|---|
| `pose_comparison.py` | 元素、电荷、键、立体构型变化；世界坐标 RMSD、质心位移、刚体对齐后的内构象 RMSD；环系及侧链分组 | 默认同一 tensor slot；原子数不同要求显式映射；同槽位不等于跨分子的化学同源映射 |
| `forcefield_evidence.py` | MMFF94s 七类能量差、逐原子力、松弛位移、二面角及其可解释性 | 总分项能量不是逐原子能量；力是分子内模型梯度；近共线二面角不作为扭转缺陷排序 |
| `external_scoring.py` | Vina/Vinardo 原姿势得分及独立局部优化副本；ProLIF 逐原子/残基接触与氢键方向 | 原姿势只经历 PDBQT 坐标舍入；局部优化不是全局 docking；这些结果当前只用于评估 |
| `polar_context.py` | 将供受体身份、逐原子 SASA 埋藏与直接极性接触关联 | 无 SASA 或未执行接触检查时为未知；无直接接触不等于无水桥；局部形式电荷不等于已确定的电离状态 |
| `outcome_context.py` | 把完整对照信息、文件哈希及来源包身份关联至增强 StatePacket | 保留原 `observations`，新包具有父包身份；不能把额外信息自动当作已激活的奖励 |

独立结果写入 `ReaderComparisonContext.json`，再绑定到 `StatePacket.with_outcomes.json` 的 `steering.outcome_context`。现有 43 项测量仍保留；ProLIF 的完整准备后证据位于附加包内，不把原测量器的缺失状态伪装为已完成。此轮没有改写原有 t=0.50 DiagnosticReport，也没有重新训练 affinity head。

推荐后续接口同时接受 `StatePacket`、原始 `DiagnosticReport`、`ReaderComparisonContext`、`DesignIntent`。消费者应核验附加文件哈希及 subject，而不能只相信路径。自动绑定已实施；让奖励构造器据此自动挑选新目标仍需下一步实现。

## MolThinker 应扩展的判断流程

1. **建立增量目标。** 对每一处早期风险区分无引导会自行消退、持续到终态、引导后新增、改善但付出其他代价。终态比较使用同一完整恢复状态的无引导结果；历史 clean、晶体配体、局部松弛副本分别保留角色。对已经自行消退的问题不再重复领取奖励。
2. **允许提出不同优化假设。** 并列考虑分子内松弛、配体整体姿势、局部基团朝向、微观电离/互变异构状态、化学图改变和新的相互作用模式。先描述哪个假设能解释证据，再决定函数。允许较大变化不等于无限制放宽位移；原子增删需要相应模型接口支持。
3. **优化可解释的缺口。** 严重约束之外保留连续的结构偏差代价；按力常数或经过检验的尺度衡量关键偏差，避免宽容差与全局平均掩盖局部高应变。加入新分项前检查是否与现有几何代价重复。图改变后重新绑定参照，跨图比较各自的自应变及共同外部目标，避免直接相减绝对 MMFF 能量。
4. **同时表示结合收益与代价。** 将有证据的定向相互作用作为软保护条件；对深埋且无已知配对的极性位点保留可审查的脱溶剂化代价假设。允许替代原有接触模式；不能仅凭“更多接触”“更短距离”奖励结合，也不能把水桥未知写成确定惩罚。
5. **识别 head 的可利用偏差。** 允许独立评分、松弛后评分变化和多准备状态的一致性否决单一 head 的获益。Vina/Vinardo 相关性高，不当成两个完全独立验证；与 pKd 的数值差不能直接相减解释成校准误差。
6. **按有效梯度调度。** 比较分项梯度方向、范数、实际注入位移、裁剪和预算，而不仅是名义权重。结构优先达到可接受区间后再扩大 affinity 探索；保留连续结构项以防“刚过告警线即停止优化”。冲突持续时修订目标或控制自由度，而不是持续上调 η。
7. **分配不同计算角色。** 可微近似承担逐步引导；非微分外部工具承担稀疏检查、候选排序和反馈。任何替代模型、有限差分或无梯度估计均单独声明误差和成本。不能将 Vina 的标量回传包装成可微 PyTorch 项。
8. **保留未知和条件目标。** 溶解度、通透性、代谢、选择性、可合成性依赖任务要求；没有目标范围的 MW/logP/QED 不进入风险惩罚。脱离训练适用域或准备不确定时降低结论强度。

输出应包括：证据角色表、自然演化与控制增量表、候选机制及被排除的替代解释、目标/硬约束/保护项表、可微性与适用性表、参数来源、独立验收规则。将调整建议放在推导文档，DiagnosticReport 保持风险描述。

可考虑的组合形式为 `独立证据支持的 affinity 收益 + 定向相互作用收益 − 连续结构代价 − 有覆盖支持的脱溶剂化代价`；几何、相互作用与能量不得重复计数。这是待验证的函数族，不是已经执行或确定优于当前函数的新奖励。

## 常用评估方向及使用位置

| 方向 | 工具与用法 | 本轮状态 |
|---|---|---|
| 价态、断连、手性、碰撞与姿势有效性 | RDKit、PoseBusters；原姿势检查，输出原子身份与失败项 | 已执行；通过不等于结合可靠 |
| 分子内应变与局部力 | RDKit MMFF；固定重原子准备 H，再在副本上松弛并分项；必要时用其他力场或 xTB 交叉核验 | MMFF 已执行；其他力场/xTB 未执行 |
| 结合姿势评分 | Meeko 准备后 Vina/Vinardo score-only；局部优化副本另行评估；GNINA 可作另一模型的评分或重排序 | Vina/Vinardo 已执行；GNINA 未执行 |
| 定向相互作用及极性满足 | ProLIF、逐原子 SASA；保留供受体、残基、距离、角度、水与质子化覆盖 | 静态直接接触已执行；水桥、持久性未执行 |
| 受体/配体准备敏感性 | 明确 pH 后生成微观状态，比较已验证的受体构象；保留准备过程与原子映射 | 仅单一模板状态；未开展 ensemble |
| 稳定性及自由能近似 | OpenMM/Amber/GROMACS 的约束松弛与采样；适用时做 MM/GBSA 或经过验证的相对自由能计算 | 未执行；不能由 docking 代替 |
| ADME、选择性与可合成性 | RDKit 描述符/筛选警示；适用时 SwissADME 类模型、靶点对照、AiZynthFinder 路线分析 | 描述符及筛选已执行；预测 ADME/选择性/路线未执行 |

工具依据：[Vina 区分原姿势评分与优化](https://autodock-vina.readthedocs.io/en/latest/docking_python.html)、[ProLIF](https://prolif.readthedocs.io/en/latest/notebooks/docking.html)、[GNINA](https://github.com/gnina/gnina)、[PoseBusters](https://pubs.rsc.org/se/content/articlelanding/2024/sc/d3sc04185a)、[SwissADME](https://doi.org/10.1038/srep42717)、[AiZynthFinder](https://molecularai.github.io/aizynthfinder/)。本轮没有向在线服务上传结构。

基线终态必须来自已完成、可用的运行；在线首次生成尚无终态时，需事先运行无引导对照或标记该证据缺失。不能把未来结果当作免费的实时信息。
