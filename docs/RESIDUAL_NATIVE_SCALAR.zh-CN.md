# 剩余需求决策与原生 FLOWR.ROOT 全程标量注入

2026-10-03。本轮实施只使用离线测试、合成可微模型及已保存的实验记录，没有调用真实 API 或生成新的分子。本文说明当前执行语义，替代历史文档中的 Executor 自适应控制约定。

## 决策与证据

MolReader 的当前 `DiagnosticReport` 保持原始状态诊断语义。独立 raw 比较新增 `residual_needs` 分页索引：每项从显式终态剩余问题出发，关联所有配置节点的化学解释、关系适用性、测量、参考和偏差，再列出当前前兆、待判断的坐标机制、有益演化保全引用、竞争解释和缺失观测。化学重分类不覆盖当前类型下的缺陷；关系消失、观测缺失和自然解决分别记录。缺少终态时不会把最后可见中间节点当作终态。

`inspect_raw_comparison(section="residual_needs")` 支持分页和因素/表征筛选；精确来源仍由 `read_raw_reference` 读取。配置中指定却未保存的节点以不可用节点表示。Host 预先生成当前诊断与跨节点索引，Reader 提交不要求先调用固定的三类读取工具。

`reader.measurement_stage_paths` 可把节点 ID 映射到仓库内已有 stage 目录。`measure_evidence_gap` 调用已实现的 MolReader 指标计算器，核对身份、坐标和原子映射后在副本上计算；结果另存 `MeasurementSupplement`，包含源文件、坐标、配置及内容 hash。`read_measurement_supplement` 按字段读取。输入或计算能力不足会明确返回缺口。补充包不修改原始 packet、报告或 `data`，后续节点的补测也不会获得当前奖励数值绑定资格。

生物专家的实际提示词与中英文技能现在围绕三个问题比较候选：终态剩下什么、当前干预通过什么机制起作用、该目标新增覆盖哪项独立必要需求。`value_assessment` 记录需求关联、可控前兆、反证、有益演化、排序理由和不确定性。原生已修复的问题需要额外价值理由才能保留；必要但缺少执行输入的需求继续延期。系统没有强制目标数量，也不自动把目标改成距离项。

数学专家分别检索与构造独立需求的物理损失，按“目标集合→局部响应→候选”推进。来源记录区分保留、特化和重构。最终交付单一标量，rank 系数进入实际表达式组合；保全进入标量项或独立评价。坐标副本工具记录分量值、尺度、系数、范数、余弦和对合成方向的贡献；有实际采样 adapter 时可执行恢复 RNG/状态的只读 live probe。副本与 live 结果明确区分，不把局部改善当作终态收益。

## Host 工作区和调用成本

`HostWorkspace` 管理产物 ID、版本、完整内容 hash、计算内容 hash、依赖和验证状态。构造成功即保存候选并返回回执；完整设计组装后，分方向引用指向该权威设计。`read_candidate`、`patch_candidate`、`test_current_candidate`、`submit_current_candidate` 支持按引用推进。完整旧调用仍留在注册表；契约可以读取概览、章节或显式全文，相同内容重复读取默认返回回执。历史版本按需读取。

数值缓存按计算内容与依赖绑定；纯推导文字修订不重算，最终仍验证并绑定准确的产物 hash。已通过的数学验证直接交给确定性 Executor。默认工具展示依据“无候选／已有候选／证据缺口／验证通过”变化，`select_tool_group` 可返回研究或显示全部工具，合法旧调用不会因暂时隐藏而成为未知工具。

`runtime.no_progress_actions` 默认 3。重复读取、重复保存、文字修饰、工具组切换和已见候选之间往返不算进展。无进展时只在下一次正常请求中加入一条英文提示，有进展后清除；没有额外 LLM 审查、异常或提交条件。供应商 token usage、费用回执（供应商提供时）、模块、阶段及请求/工具定义的序列化字节数写入 `api_usage`；缺失 usage 标记为未知。字节数不是 token 或精确 HTTP 包大小。

## Executor 与迁移

正式采样每步只做：同次原生 forward → 标量奖励对当前坐标的完整回传 → 原生更新 → `guidance_weight * adapter.inject(gradient, dt)`。FLOWR 的 `inject` 为 `dt * gradient`。奖励函数和外部权重在本次续采样中固定，化学参数按声明的当前状态规则解释。默认求导覆盖目标分子的全部原生活跃坐标，保留 padding、其他 batch 和明确固定变量边界。

这条路径移除了位移裁剪、累计预算、引导窗口/步数上限、共同下降、提议约束、回溯、奖励非退化检查、图变化暂停和自动调权。MolMonitor 与图复核独立且默认关闭，直接执行不调用它们；Executor 不启动模型审核回合。零梯度记为零位移并在下一步继续求值。缺失必要分量、非有限数值或张量错误会保存失败记录和 `resume_failed.pt` 并结束运行。累计路径仅作统计。

配置使用 `runtime.guidance_weight`（Agent）及执行 JSON 的 `guidance_weight`（采样），不会与 `monitoring.max_strength`、旧 `budget.strength` 或 `reward_weight` 相乘。旧预算、窗口和控制状态可读并记录为不生效。历史标量契约可保留科学绑定进行加载；`common_descent` 或提议约束设计明确返回重设计需求，不自动转换。`scripts/test_5i0b_api_weights.py` 已改为使用相同奖励、通过唯一外部权重区分实验臂。

## 本轮验证边界

全量离线回归结果：438 项通过，耗时 295 秒。随后新增旧标量契约迁移测试，并与原有版本绑定测试一起运行，2 项通过；迁移只允许忽略旧执行元数据，不能改变科学或计算绑定。全量测试有 1 条历史离散梯度工具的 PyTorch 警告，该工具未接入当前直接注入路径。`git diff --check` 通过。

新增合成测试覆盖：各剩余步骤的直接公式；高权重未裁剪；零权重与原生一致；零梯度继续；全坐标回传与固定边界；其他 batch 隔离；self-conditioning、类别随机流程和断点恢复；计算失败的真实诊断；契约回执、阶段回退、无进展提示及数值缓存；可选 live probe 的只读性。API 接线用脚本模型测试，检查实际输入包含新指引以及 Executor/Monitor 没有模型调用。

已保存的 `5i0b_glm_10_100_20261002_2030/attempt_08` 比较记录包含 6 个节点和 171 条追踪项。新索引分类为自然消失 64 条、终态关系不适用 105 条、终态仍有缺陷但中间观测存在缺口 2 条；后两条均为 `structural_alerts`。78 条追踪包含化学身份变化。源 comparison 的 SHA256 为 `3f13449577063633f5c72eef4d61eca2f3bcdacf18320117223f2c832ee979ea`。

这些计数是已有路径的证据整理，不能把“不再适用”计作被修复，不能据此认定结构警示一定可通过坐标梯度修复，也不能证明新版奖励能提高亲和力、可合成性或终态质量。本轮没有这类新实验结论。
