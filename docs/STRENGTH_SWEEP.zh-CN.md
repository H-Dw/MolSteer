# 引导强度配对实验

本实验从同一 `5i0b_A__5vef_M77 / ligand_002` 的 t=0.50 状态续生成至 1.00，只改变外部梯度引导强度，保持奖励内部系数和接受约束不变。执行器默认强度没有调高。

权重网格为 `0、0.3、1、3、10、30、100、300`，各使用三个配对的后续随机状态。S0 恢复共享运行检查点的 RNG，S1、S2 仅重新设置后续随机性。这不是三个独立分子样本。历史快照缺少自条件缓存和 RNG；共享检查点结合了精确恢复的历史状态张量与重建的隐藏上下文。

## 复现与配置

参见[英文复现命令](STRENGTH_SWEEP.md)。配置为 `experiments/guidance/strength_sweep.json`，需要服务器现有模型权重、受体与历史快照；输出目录必须新建。配置选择 GPU 1，使用前应检查该设备是否空闲。保留最高 float32 矩阵精度和有限差分预检。没有新增安装包，图表使用现有 matplotlib。

本实验单步额外位移上限为 0.02 Å，每原子累计注入路径上限为 0.5 Å。这些约束不等于对模型原生移动距离或相对无引导轨迹差异的限制。

`guidance_interval: [0.5, 0.9]` 按名义积分比例 `0.5 <= step / integration_steps < 0.9` 注入梯度；日志同时记录模型时间。不设置该字段时，保持原先整个后续区间的行为。区间合法性检查不会改变合法运行的数值结果。

## 结果与边界

- `sweep_manifest.json` 记录配置、检查点与奖励哈希、随机状态来源。
- `guidance_trace.jsonl` 记录方向余弦、预测器梯度传递、裁剪、接受位移、拒绝原因和目标分量。
- `tensor_trace.pt` 保存逐步坐标和类别，包含更新前的原生终点预测。
- `analysis.json`、`comparison.csv` 汇总配对结果和分阶段动力学；`schedule_comparison.json` 给出后期关闭引导的消融和干预前轨迹一致性检查。
- 各运行 `evaluation/*/{t_0.75,final}` 保存 StatePacket 和中英文 DiagnosticReport。

canonical SMILES 相同用于化学图比较，不代表原子槽位一一对应。跨运行坐标差基于模型槽位，不称为化学对齐后的 RMSD。改图结果不参与同图应变比较。MMFF 局部松弛应变是独立质量代理，不是当前优化的奖励或结合自由能。PoseBusters 检查通过及未检出碰撞，不代表筛选警示和覆盖限制消失。

局部位移保留指标只衡量固定自条件与共同随机噪声的一次线性 FLOWR 更新，不等同于整条随机轨迹的因果效应。后期关闭引导的配对消融提供了另一类证据，干预前轨迹完全一致。
