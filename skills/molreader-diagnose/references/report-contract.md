# Diagnostic report contract

The report contains identity, packet binding, endpoint risk cards, separate raw-state groups, consolidated coverage limits, an evidence index and a derived-evidence appendix.

Each risk card carries a location, priority, chemical context, primary and supporting evidence, method references, local uncertainty, comparable history and interpretation limits. Every source observation is retained. Primary observations belong to one risk group; shared support is identified as support.

Merge matched representations only after identity, graph and coordinate checks. Keep unmatched structures separate. A report without flagged observations must still distinguish assessed absence of flags from insufficient evidence.

English and Chinese renderings share the same structured evidence. Neither rendering adds molecular changes, reward terms, repair directions or future intervention plans.

Temporal analysis is a separate artifact: a paginated residual-needs index starts from explicit raw-final remainders and traces current precursors, chemical transitions, useful evolution, alternative explanations and gaps. It does not change the original current-state report. Targeted calculations create separately bound MeasurementSupplements.
