# MolThinker: remaining needs and scalar reward construction

[中文](SKILL.zh-CN.md)

## 1. Ground the decision

Start with the native continuation residual-needs index and counterevidence; then trace current controllable precursors. For every candidate answer: What remains at the explicit raw final? Through which current coordinate mechanism could intervention help? What independent necessary need would adding this goal cover?

Inspect all configured nodes using their own chemistry, relation applicability, measurements, references and remaining deviations. Identity transitions and defect persistence are separate facts. Preserve recurrence, late emergence, natural clearance and observation gaps. Without an explicit final, terminal status remains unknown. Later observations do not become current numerical evidence.

Integrate geometry, conformation, sterics, contacts, burial, chemical identity and measured affinity/SA/stability where available. Global co-evolution is association, not regional causality or measured intervention benefit. Record competing explanations and targeted measurement gaps. Deprioritize naturally resolved problems unless earlier repair has a stated extra benefit and acceptable interference hypothesis.

Choose the minimum sufficient set for remaining intervention needs. Compare independent needs before merging. Shared atoms, alert count and implementation convenience do not establish value or sufficient coverage. Necessary unsupported goals remain deferred; zero, one or multiple optimization goals are valid. Record need IDs, current mechanism, independent coverage, preservation, uncertainty and pairwise rank reasons in value_assessment and public decision records. Reconsider these choices when mathematics provides contradictory mechanism evidence.

## 2. Research, derive and construct

Use [core targets](references/core-target-and-shape.md), [knowledge transfer](references/knowledge-guided-composition.md), [regional composition](references/regional-function-architecture.md) and [the handoff](references/reward-design-ir.md) on demand.

For each independent selected need, retrieve relevant physical functions; distinguish original source roles from retained, specialized or newly constructed parts. Determine target sets and scale origins, derive local response, then construct candidates. Keep chemical hypotheses, reference values, tolerance assumptions and units explicit. Source consistency alone does not supply the reasoning.

## 3. Deliver one scalar

Deliver one differentiable scalar reward, with rank coefficients inside its actual composition. Encode chosen preservation as scalar terms or explicitly retain independent evaluation. Compare component values, physical scales, coefficients, gradient norms and directional contributions at the same state, frame and derivative space. Use a read-only live response probe when provided; coordinate-copy results and unrun live tests must be labeled separately. Improve scale, curvature and composition when response is excessive or dominated by one term. Local improvement is not a terminal-quality result.

Executor evaluates the same reward at every remaining native step and adds fixed external guidance_weight times native dt times its current-coordinate gradient. The native grid, categories, self-conditioning and random stream remain native. Observable support does not restrict movable coordinates; only native masks and explicitly fixed variables do. Current chemical rules update parameters without freezing an initial graph. Zero gradients are reevaluated next step; undefined components fail the run with recoverable state. Legacy projected directions or proposal constraints need an explicit scalar redesign.

## 4. Work through artifact references

Host performs initialization, evidence binding, versioning and deterministic serialization. Construction saves the candidate and returns its ID/version. Read sections, patch fields, compare response, test and submit by reference. Return to research when a concrete gap emerges; keep the candidate. Full schemas and archived artifacts are available on demand. A no-progress notice asks for a targeted fact, a substantive construction/test step, reconsideration or explicit deferral; it is advisory.

Return public evidence/decision summaries, source transfer, the scalar expression, component response records, validation scope and independent evaluation limitations. Reference nodes, goals, formulas, coefficients and target counts are task/configuration choices.
