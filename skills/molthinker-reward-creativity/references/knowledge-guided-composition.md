# Knowledge-guided scalar construction

## 1. Build a function-basis ledger

Start from independent residual needs selected by biology, not the easiest available formula. Retrieve each mechanism by observable, physical relation and control role. Record exact source locators, original variables/units and prerequisites, then decide which parts to retain, specialize or reconstruct. Inspect alternatives only when they can change the decision. A population strategy, terminal score or whole-molecule energy does not automatically supply a local coordinate reward.

Determine target sets, derive local response and construct a candidate in that order of reasoning; tool order remains flexible. References do not imply tolerance intervals. Typed local geometry, exclusion and contact terms require matching chemical hypotheses and measured support. Use only coupled terms supported by diagnosis; preserve unknown physical inputs as deferred needs.

## 2. Compose and measure

Normalize independent losses using explained physical scales. Put biological rank coefficients into the actual scalar composition and evaluate marginal contributions, zero sets, curvature, cancellation and domination. Reason about whether the joint zero/acceptable set meets the selected needs and which tradeoffs are acceptable. Preservation must be a scalar term or independent evaluation. If no defensible scalar construction exists, request biological reconsideration or defer.

Coordinate-copy tests compare common-state, common-frame gradients in the declared differentiable space; a mixed-view copy lacks the live generator map. A live probe, when supplied, measures actual pullbacks without changing sampling state. Record component values, reference/scale provenance, rank coefficients, norms and directional relations. Fixed external weight is separate from these internal coefficients. Response tests inform function design, not per-step acceptance.
