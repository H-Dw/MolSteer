# 知识引导的函数组合

当 MolThinker 需要创建不能从单个知识条目直接复制的奖励时使用本说明。目标是在组合多个机制时保留知识库函数的物理含义，并使最终目标与当前诊断状态对应。

## 1. 建立函数基台账

针对每个优化目标，按机制而不是仅按关键词检索函数，记录：

| 字段 | 必需含义 |
| --- | --- |
| 知识条目 | 来源标识、位置与原始方程 |
| 物理问题 | 函数测量的可观测失效或目标关系 |
| 前置条件 | 化学图、原子类型、质子化、受体准备、参照或种群要求 |
| 原始角色 | 坐标势、分类偏好、约束、终态评分、反证、选择器或估计器 |
| 特化方式 | 绑定原子、受体区域、目标集合、尺度、方向和作用范围 |
| 组合角色 | 直接修复、耦合风险控制、保持、任务缺口或反证 |
| 排除条件 | 使函数不适用或与其他函数重复的证据 |

一个函数提到同一属性，并不表示该目标已经得到充分表达。函数基应以最小集合覆盖直接修复机制、主要捷径和必须满足的有效性边界。当新增条目既不改变公式，也不增加独立反证路径时停止检索。

## 2. 将函数特化为归一化缺口

设知识函数对应可观测量 $z_k(X,G)$，有证据的可接受目标集合为 $T_k$，尺度为 $s_k$：

\[
F_k(X,G)=\phi_k\!\left(
\frac{\operatorname{dist}(z_k(X,G),T_k)}{s_k}
\right)\ge 0,
\]

其中 $F_k=0$ 表示目标已经满足。最小距离、碰撞穿透和定向目标应保留单侧语义；扭转、手性和方向关系应按需要使用周期或有符号残差。目标不可用时不能把残差记为零。

多条测量描述同一因果区域时，先去除重复视图，再根据失效语义选择区域算子：

- 单个局部严重异常使用平滑最大或稳健上尾；
- 相互独立的轻微偏差使用归一化均值；
- 相互作用对象不确定时使用匹配或软匹配；
- 只有化学图、原子类型和微观状态前提成立时，才使用力场或分解物理能量。

由此得到区域缺口 $F_r$。只有在目标、匹配参照或非回退裕量使零集合具有明确含义时，全分子任务效用才可转化为缺口。

## 3. 仅在多个目标确有必要时推导组合

入选核心目标包含多个独立缺口时，先判断它们是否允许补偿、是否每项都必须达标、是否有经验证的优先顺序，或在真实可编辑空间中相互冲突。只有一个充分目标时不需要跨目标聚合。需要聚合时也必须重新推导，不能选用记忆中的最终方程。

先声明预期响应规律和联合可接受集合：修复单一原因、满足多个目标集合的交集、允许有量化依据的折中、执行优先顺序，或求可行共同方向。再推导零集合和敏感度符合该规律的结构。最大值、范数、约束求解或标量求和都只是有前提的候选。除非存在经过验证的估计器，否则化学图或微观状态操作应与连续导数路径分开。知识表可能支持组成项的局部势，却不一定为新的聚合算子提供文献来源。

生成的组合必须回答：

- 在各相关状态区间，哪些组成项获得边际压力，以及某个未达标的必达目标是否能被补偿；
- 某个保留目标是否会在修复判据通过前获得严格为零的压力；
- 两个缺口交换排序或接近目标时，响应如何变化；
- 哪些参数控制曲率、平滑、优先级与图排序，其尺度从何而来；
- 哪些知识条目支持**局部函数**，哪些组合规则是本次新推导的。

对候选组合进行符号或自动敏感度推导，并与预期响应规律比较；若最优点仍允许命名缺陷未修复，也应淘汰。只有机制结构确实需要时才使用层级组合。硬约束、缺失测量和无关原始分数不能进入共同软目标集合。

## 4. 按角色加入知识函数

组合奖励可以使用多个知识函数家族，但不能退化为原始量的直接求和：

- 局部区间、排斥、方向、扭转或立体化学函数定义修复残差；
- 前置条件成立时，分子力学或残余力函数覆盖耦合的分子内应变；
- 受体和微观状态证据充分时，类型化接触、定向相互作用、静电或暴露函数定义界面缺口；
- 锚点、口袋占据或运动函数用于保持有依据的上下文，不能将全部原子强制拉回早期姿势；
- affinity 或 docking 函数依据导数可用性充当任务缺口、终态选择器或独立反证；
- 分类偏好、显式枚举或种群加权在连续坐标梯度之外运行，除非存在经过验证的估计器。

新增严重碰撞、化学有效性失败、断连、固定原子和必须保持的身份属于拒绝条件，不能用其他收益购买。

## 5. 淘汰不可靠组合

出现以下任一情况时淘汰或修订候选：

- 将单位不兼容的原始观测直接相加；
- 同一缺陷的多条告警产生多个权重；
- 分阶段控制器从标量梯度中移除尚未稳定修复的目标；
- 阶段在与原生基线相等时解锁，而没有有证据的正向裕量；
- 宽松 flat-bottom 在缺陷仍具有物理意义时使其梯度归零；
- 没有匹配参照和独立反证却直接追逐模型 head；
- 没有导数估计器却把黑箱评分、分类 argmax 或图代价描述为可微；
- 重绑定图相关参照后没有复查原始修复判据；
- 用内部权重补偿外部引导不足，或用提高 $\eta$ 掩盖无效目标。

## 6. 分开校准目标分配与引导强度

对每个组成项测量掩码前、掩码后和投影后的坐标梯度。比较提议注入位移与匹配原生更新，并记录裁剪和路径预算。区分：

- 语义支配：某个归一化缺口在科学上被过度优先；
- 数值支配：优先级相近，但一个导数尺度压倒其他项；
- 执行衰减：掩码、投影或生成器雅可比移除了大部分有效梯度；
- 原生冲突：原生更新持续抵消或反转干预。

语义或数值失衡时修订 $F_k$、$s_k$ 或 $w_k$；执行衰减时修订可编辑范围、投影或外部强度 $\eta$。根据投影和裁剪后的引导位移相对原生位移以及信赖域行为选择 $\eta$，不能仅根据奖励数值大小推断。

## 7. 必需推导记录

最终推导必须展示：

1. 已诊断因果区域与明确优化目标；
2. 检索得到的函数基及适用性结论；
3. 每个特化后的 $F_k$ 及归一化来源；
4. 集合 $A$ 的成员和排除项；
5. 生成的聚合机制、敏感度行为及被淘汰的替代架构；
6. 各组成项的导数分配，以及单独的 $\eta$ 校准；
7. 硬约束、图变化语义与独立反证测量。

如果这些内容无法得到支持，应将设计保留为假设，不能标记为可执行。
