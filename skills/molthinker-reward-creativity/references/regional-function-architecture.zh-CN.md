# 区域标量架构

即使共享原子，也要区分独立剩余机制。只有机制依据充分时才合并重复测量。检索互补物理信息用于识别代理漏洞，不为凑固定项数。完整能量需要对应可用计算器，未支持的区域能量归因保持未知。

分别构造物理损失，再依据生物价值排序、尺度可比性和实测导数关系选择标量组合。rank 系数必须改变实际响应。记录分量值、尺度、系数、范数和方向贡献。测试抵消、支配、化学解释变化及已修复/未修复状态。保全进入同一标量或独立评价；不能表达为所声明标量的控制方向保留为重新设计需求。

续采样期间函数固定；已声明的当前化学解释规则可以更新参数。求导覆盖目标分子原生活跃坐标及明确固定变量边界，观测支持不自动成为移动边界。目标、节点、函数和系数由任务动态决定。
