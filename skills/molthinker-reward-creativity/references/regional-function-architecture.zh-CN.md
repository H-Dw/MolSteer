# 局部函数组成架构

提供控制函数知识表时，用本指南把已诊断的局部缺陷映射到可用的作用机制。知识表提供函数结构与前提，不直接提供当前分子的目标值、权重或亲和力改善证据。

## 从局部原因选择函数族

| 局部问题 | 应检索的已报道架构 | 特化与排除条件 |
| --- | --- | --- |
| 键长、键角或接触距离是否越出可信区间？ | 依化学图确定的 flat-bottom 区间势及单侧变体 | 将原子角色、化学身份、单位和区间绑定到当前假设。只惩罚涉事关系；不从噪声坐标直接猜目标值。 |
| 是否存在过近的配体–受体或分子内原子对？ | 成对排除球或最小距离势 | 对涉事原子对或邻近界面使用单侧穿透罚；新出现的严重碰撞属于可行性失败。 |
| 关键基团是否漂移或失去空间作用？ | 锚点/各向异性保持势；定向特征的一致势 | 只保持有依据的锚点和方向。把所有原子固定在早期姿势会阻碍修复。 |
| 手性、双键或共轭平面是否存在几何风险？ | 有符号手性、二面角窗口或平面势 | 将平滑局部项与精确立体化学检查配合；低罚值不能证明最终构型正确。 |
| 原生续推后局部应变是否仍在？ | 可分解的分子力学势或残余力势 | 找出对应的键、扭转或非键邻域。要求有效化学图、原子类型与质子化；全分子能量可用作保护性检查。 |
| 是否有作用方向或埋藏极性不匹配？ | 定向药效团势、分型界面势、有条件的 SASA 或静电互补势 | 核对供受体角色、受体准备、电荷状态以及预期暴露或方向；缺失水和微观状态时降低解释力度。 |
| 是否需要终态任务评分？ | 对接/亲和力评分、目标性质势、候选排序或种群权重 | 声明其角色是可微目标、终态反证、候选选择还是种群操作；不可把黑箱评分或采样权重称作坐标梯度。 |

这些函数族对应知识库的几何、物理化学及终态搜索类别。特化前阅读相应条目的原式、来源、前提与梯度对象。文献中的数值常数不会自动适用于新化学图和受体。

## 先构造机制，再确定权重

对每个独立区域 $r$，定义已映射的化学身份 $G_r$、可观测量 $z_{r,m}(X,G_r)$、有证据支持的目标集合 $T_{r,m}$、物理尺度 $s_{r,m}$ 与函数族 $\phi_{r,m}$。局部残差可表示为

\[
e_{r,m}=\phi_{r,m}\!\left(\frac{\operatorname{dist}(z_{r,m},T_{r,m})}{s_{r,m}}\right).
\]

根据失败性质选择区域内聚合算子 $\mathcal A_r$：单个严重缺陷用最大值或稳健上尾，多个独立轻微偏差用归一化均值，作用对象不明确时用特征匹配。各关系按物理尺度归一化后，可用平滑最大值近似最严重的局部缺口；不能将无关的全分子评分混入同一个最大值。令 $L_r=\mathcal A_r(\{e_{r,m}\})$。告警数、原子对数、检索命中数和重复视图不能增加区域重要性。

局部机制确定后，再决定各区域与任务效用 $U$ 的关系。先区分独立且必须达标的区域、互为替代解释的区域，以及确实允许损益补偿的测量。推导最优点符合修复判据、敏感度符合该决策的联合目标或约束控制器。最坏缺口包络、范数、分阶段控制和直接求和都只是有条件的候选，没有默认答案。若采用阶段切换，须以持续检查和回退规则保留已修复区域。未校准的终态评分不能直接升级为坐标势。

## 化学身份改变时保留评价含义

将依赖化学图的参照绑定到对应假设。候选图改变后重新计算适用参数，并分别检查化学有效性、原有局部任务及新暴露的风险。不同化学图的低力场能量不能证明起始化学图的缺陷已修复。明确评分方向、梯度路径、固定区域和原生对照。知识库函数可能是目标、约束、反证评分或选择算子，这些角色不能互换。
