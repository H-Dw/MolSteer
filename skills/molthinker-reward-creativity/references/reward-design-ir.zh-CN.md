# 标量奖励交付

## 科学记录

保留 packet/report ID、raw 比较 ID、剩余需求 ID、当前前兆证据、独立覆盖、生物排序与延期项。逐分量保存观测量、当前化学解释、单位、物理参考与尺度、来源迁移、表达式和不确定性。未来 raw 引用仅作上下文。明确保全属于标量还是独立评价。

## 计算契约

交付一个标量表达式及分量/rank 组合、化学解释规则、坐标映射、明确固定变量及唯一外部 guidance_weight。Executor 每个剩余原生步骤使用同一奖励，从同次 forward 回传，保持原生采样并加入权重×原生 dt×梯度。自然零梯度有效；必要分量缺失或数值非有限时报计算失败并保存可恢复状态。旧控制器产物可读，但执行前需要标量重设计。

## Host 工作区与验证

Host 管理产物 ID、版本、hash、依赖与数值缓存。构造即保存并返回回执；按字段修订、按引用测试与提交。契约章节和完整历史按需读取。无候选时侧重研究，有候选时侧重修订测试，出现具体缺口时返回研究；完整注册表调用仍然合法。进展依据新证据、问题回答、计算内容改变和验证推进；重复读取、文字修饰与候选往返不计进展。

来源一致性、坐标副本导数、可选 live 回传与终态实验分别报告。按模块与阶段记录供应商 token usage 和请求/工具定义大小；缺失 usage 为未知。无进展提醒为建议，不增加模型调用或提交条件。
