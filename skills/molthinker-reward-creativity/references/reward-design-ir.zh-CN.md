# RewardDesignIR 与架构选择

在核对 StatePacket 和 DiagnosticReport 之后、编写奖励公式之前使用本指南。RewardDesignIR 用于保存奖励设计问题的科学含义，使架构选择与 RewardProgram 编译可以审计和修订。

## 1. 必需对象

| 对象 | 必需内容 | 决策作用 |
| --- | --- | --- |
| `identity` | 靶点、样本、阶段、StatePacket 与 DiagnosticReport 身份及来源摘要 | 防止跨状态混用证据 |
| `control_context` | 时间方向、剩余步程、受控表示、连续与分类变量、可编辑与固定范围、实时导数路径、原生更新语义及预算 | 判断哪些操作能够执行 |
| `regions` | 每个独立因果缺陷或设计区域一条记录 | 保留局部性，防止无关缺陷被平均 |
| `objective_nodes` | 直接修复量及其目标、残差、尺度、角色和有效条件 | 定义奖励改善的含义 |
| `preservation_conditions` | 不得退化的身份、相互作用、姿势或骨架属性 | 防止通过无关变化提高分数 |
| `hard_constraints` | 不可补偿的有效性和安全条件，包括基线、阈值、范围和拒绝语义 | 将不可行提议排除在权衡之外 |
| `terminal_utilities` | 用户声明的任务结果、方向、目标或区间、评价器和不确定性 | 将任务表现与局部修复分开 |
| `discrete_operators` | 候选来源、编辑通道、排序或重采样规则、信任策略和接受检查 | 在不虚构坐标梯度的前提下表达身份改变 |
| `architecture_candidates` | 可行组合和被淘汰的替代方案 | 通过比较选择架构，而非沿用习惯 |
| `selected_architecture` | 选择门槛、决策规则、假设和预期失败方式 | 解释为何选择该结构 |
| `execution_contract` | 梯度对象、坐标系、掩码、时间激活、单步与累计预算、拒绝回滚和恢复状态 | 在执行中保持数学含义 |
| `feedback_contract` | 监测信号、修订触发条件和停止条件 | 建立生成结果到奖励修订的闭环 |
| `provenance` | 每个设计元素对应的证据、知识条目和目标声明 | 支持审计和后续修订 |

## 2. 区域记录

每个区域表示一个独立因果问题。即使不同区域共享原子，也应保留独立区域身份。

区域记录包含：

- 稳定的区域标识和优先级；
- 证据视图：噪声状态、预测终点、解码结构或具有明确映射的组合；
- 原子、键、立体化学和受体身份及局部邻居；
- 当前化学图或微观状态假设及可信替代；
- 直接可观测量、测量值、单位、参照和不确定性；
- 在匹配原生续推中的持续性；
- 相对可解释容差的严重度和局部归因可信度；
- 可编辑范围、固定边界和受体区域；
- 描述什么必须变为真的修复判据；
- 描述什么必须继续为真的保持判据；
- 可能提高代理分数但未修复区域的禁止捷径；
- 暂停或结束该区域控制的条件。

当告警、代理量和全分子支持描述同一原因时，应归入同一区域。除非它们测量独立失败，否则不能各自成为目标节点。

## 3. 目标节点

目标节点记录：

| 字段 | 含义 |
| --- | --- |
| 角色 | 局部修复、保持条件、终态效用或仅监测 |
| 可观测量 | 受控表示上的可测函数 |
| 目标 | 有证据的点、区间、集合、排序或方向 |
| 残差 | 到目标的距离，并明确符号与零值集合 |
| 尺度 | 物理容差、参照变异或匹配原生尺度 |
| 函数族 | 区间、排斥、方向、立体化学、能量、相似性或任务效用架构 |
| 作用范围 | 允许影响该节点的原子、键、姿势变量或分类通道 |
| 算子 | 坐标梯度、分类提议、排序、重采样、终态评价或硬拒绝 |
| 有效条件 | 解释该节点所需的化学、几何、准备和模型假设 |
| 覆盖状态 | 可用、部分、不可用或有条件可用，并说明原因 |
| 来源 | 诊断证据、目标声明和知识条目 |

归一化局部残差写为：

\[
e_{r,m}=\phi_{r,m}\!\left(\frac{\operatorname{dist}(z_{r,m},T_{r,m})}{s_{r,m}}\right),
\]

其中 \(\phi\) 的零值集合应与有证据支持的可接受集合一致。保留原始可观测量，不以归一化残差替代原始数值。

尺度来源按以下顺序优先：

1. 经过验证的任务特定容差或目标分布；
2. 匹配参照集合或匹配原生续推；
3. 已核查适用性的物理、文献或力场容差；
4. 明确声明修订触发条件的实验尺度。

不能仅根据告警数量、原子对数量或当前残差大小推断尺度。获得初始梯度诊断后，可据此识别数值支配并修订参数，但不能消除尺度的物理含义。

## 4. 候选架构族

生成所有满足前提的架构族。硬约束始终位于软聚合之外。

### 归一化直接求和

只有各目标具有独立含义、已经归一化且允许科学补偿时，才检索线性聚合架构。如果多个小改善可以抵消严重局部失败，则淘汰该架构。实际表达式应由当前目标节点重新推导，不能保留通用模板。

### 必达目标集合的交集或瓶颈

适用于多个独立修复判据都必须成立的情形。推导零集合或可接受集合等于各目标交集的目标；若标量目标会允许损益补偿，则改用显式约束。最坏违反量、范数或逐区域约束都只是候选，须检查敏感度、可行方向及并列最大值附近的行为。共同集合只包含可计算且兼容的软目标，不能包含缺失测量、硬约束或无关终态评分。现有函数表支持局部形状，并不自动验证新的聚合规则。

### 分阶段或词典序控制

先降低最高优先级区域损失，直到修复判据和不退化余量通过；再激活下一缺陷区域或终态效用，同时将已修复区域保留为约束。阶段进入、退出、回退和退化条件应来自可观测量，不能只按经过步数切换。

### 显式约束目标

适用于任务效用具有明确意义，但局部有效性、严重碰撞、固定身份或保持要求不能被任务收益补偿的情形。说明约束通过投影、提议拒绝、接受过滤还是独立可行性过程实现。

### 连续与离散混合控制

将坐标可微损失与离散算子分开。只有来源角色和现有分数支持时，才检索分类偏好或排序机制。冻结边缘分数只表示相对模型偏好，不能称为校准化学概率。说明替代图如何产生、算子何时用于排序、哪些化学检查控制接受，以及离散信号是否影响连续导数。如果没有候选生成或接受机制，则把离散项保留为仅监测信息。

## 5. 候选比较

对每个候选的下列标准给出通过、有条件通过或失败，并绑定证据：

1. 与各高优先级区域原因的一致性；
2. 目标和参照的有效性与来源；
3. 目标独立性及是否避免重复加权；
4. 物理归一化和参数可识别性；
5. 梯度或选择路径是否可用；
6. 局部作用范围及预期梯度泄漏；
7. 补偿安全性和硬约束覆盖；
8. 奖励捷径与投机风险；
9. 化学图、电荷、立体化学或姿势变化后的行为；
10. 与原生动力学的预期一致或冲突；
11. 执行兼容性、预算和评价成本；
12. 可用于证伪该假设的独立测量。

按以下顺序应用选择门槛：输入与有效条件、不可补偿约束、直接修复能力、图变化稳健性、执行可行性，最后才是终态效用和效率。不能把这些门槛压成任意元评分。记录为何选中当前候选，以及什么证据会推翻该决定。

## 6. RewardProgram 编译契约

RewardProgram 由选定的 RewardDesignIR 编译生成。任何目标或参数都必须能追溯到中间表示。

保留下列部分：

- 身份与选定架构；
- 按区域组织的目标、原始可观测量、归一化残差和修复判据；
- 区域级和跨区域聚合；
- 保持条件与终态效用；
- 带有参照基线和拒绝行为的硬约束；
- 离散算子及其提议、排序与接受角色；
- 化学图转移和参照重绑定策略；
- 时间激活及依状态变化的阶段切换；
- 梯度或选择对象、掩码和控制预算；
- 预期失败方式、监测信号、修订触发条件和停止条件；
- 完整诊断证据和知识来源。

编译必须保持角色。不能因为软罚更容易执行就把硬约束改为软目标；不存在有效导数路径时，不能把终态评价器改称坐标梯度；不能因不同区域共享原子就将其合并。如果现有执行机制不支持选定架构，应报告不兼容，并保留原始设计供后续支持。

## 7. 由结果驱动的修订

使用匹配原生行为和独立终态测量区分四种情况：

- 目标和指定缺陷都改善：保留假设并继续校准；
- 目标改善而缺陷未修复：修订可观测量、目标、作用范围或捷径控制；
- 局部梯度正确但原生动力学将其消除：先修订激活、注入或预算，再考虑重定义目标；
- 化学有效性、保持条件或终态结果退化：淘汰候选或加强相应不可补偿规则。

不能仅因代理目标反应较弱就提高权重或执行强度。记录限制来自奖励含义、导数路径、原生冲突、分类可行性还是控制预算。
