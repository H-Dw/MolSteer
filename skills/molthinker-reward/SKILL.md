# MolThinker Reward Routing

Use [creativity](../molthinker-reward-creativity/SKILL.md) by default for custom rewards. It retrieves a knowledge-function basis, specializes normalized deficits, compares structured aggregators and separates objective allocation from guidance strength before compiling a RewardProgram. Use [selection](../molthinker-reward-selection/SKILL.md) only when the user explicitly requests selection and specialization of existing reference functions without new composition. Read the selected workflow before deriving a reward. Chinese instructions: [SKILL.zh-CN.md](SKILL.zh-CN.md).
