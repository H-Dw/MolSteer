# MolThinker Reward Routing

Use [creativity](../molthinker-reward-creativity/SKILL.md) by default for custom rewards. It discovers the smallest sufficient core target set, derives local function shapes from evidenced acceptable sets, compares composition and constraint strategies, and separates reward meaning from guidance strength before compilation. Use [selection](../molthinker-reward-selection/SKILL.md) only when the user explicitly requests selection and specialization of existing reference functions without new composition. Read the selected workflow before deriving a reward. Chinese instructions: [SKILL.zh-CN.md](SKILL.zh-CN.md).
