# Evidence input contract

Distinguish the current state, endpoint prediction, decoded structure, receptor context and generation metadata. Preserve the source digest and meaning of every representation.

Category channels require explicit vocabularies. Element indices are not atomic numbers; charge classes describe formal charge unless documented otherwise. Distinguish probabilities, logits and sampled labels. Record unresolved special tokens rather than assigning a convenient element.

Coordinate transform verification precedes interface interpretation. Keep original atom slots after masking. A geometric transform, identity map and matching graph are all required before merging decoded and predicted evidence.

Supplement existing packets by creating a new identity linked to the parent. Never present missing runtime masks, derivative access, targets, particle weights or budgets as measured facts. Generation samples and document examples do not supply those declarations.
